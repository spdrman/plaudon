Plaudon Branding Kit
====================

Contents
- logo/: SVG masters and PNG exports
- icons/web/: favicon set, apple touch icon, web app icons, manifest
- icons/mobile/: iOS/Android app icon exports
- icons/desktop/: PNG, ICO, and ICNS desktop icon assets
- brand/: HTML brand guide, CSS variables, JSON design tokens

Open brand/branding-page.html in a browser to review the branding page locally.

Logo SVGs (logo/*.svg) have a viewBox and no fixed width/height, so they scale to whatever box embeds
them. plaudon-ribbon-pulse.svg, the lockup and the blue monochrome switch palette with
prefers-color-scheme (dark). The PNG/ICO/ICNS exports are rendered from these SVGs (light palette).
plaudon-ribbon-pulse-original.png is the reference artwork the SVGs were rebuilt to match.
