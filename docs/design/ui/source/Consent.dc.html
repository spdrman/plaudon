egui mapping: consent sheet
egui::Modal::new(Id::new("cloud-consent-sheet")).backdrop_color(overlay), Frame fill bg_raised, radius.large, window_shadow. Width 620 pt, content in a ScrollArea so it survives the 560 pt minimum height.
Facts are an egui::Grid on a bg_canvas Frame. Scopes are radio_value rows; the selected row also fills bg_selected so the choice isn't just a dot.
Built-in refusals, as built
The sheet opens on Ask every time, which authorises nothing. If zero retention is required and the route can't confirm it, Approve is replaced by the refusal "Zero retention cannot be confirmed" and nothing is sent.
An unknown price is "Unknown", never $0, and Approve stays disabled until the cost checkbox is ticked.
Focus and keys
Focus lands on the first control and stays inside the Modal; Escape closes it as Cancel (close_overlay, not rebindable). Tab order follows reading order; the primary sits last, on the right.
Status bar shows the enforced policy: Local-only is off here, so the warning tone reads "Network allowed for providers you enable".
