Plaudon desktop UI

One design for the egui shell: every screen the app has, light and dark, with the tokens and the egui calls to build it.
✓ All pairs AA, measured egui 0.36 / eframe 0.36

The product rules the UI has to show

Local-first. Local-only mode is on from first launch. The badge renders what the egress gate answered, never the stored preference.
No account. Nothing in the shell asks you to sign in. The PLAUD account route lives behind Devices and says it's PLAUD Cloud.
Bring your own key. The OpenRouter key's presence is shown, never its value. A key is never consent.
Claims are source-anchored. Every claim says whether its anchor resolved, and seeks only when the transcript has real timing.
Unverified means unverified. Hardware reads "Unsupported" or "Not evaluated". Unknown is "Unknown", never 0:00 or $0.
Never colour alone. Every status has a glyph and a word.

What egui is allowed to draw here

Panels (TopBottomPanel, SidePanel, CentralPanel), Frame with CornerRadius and Stroke, Grid, ScrollArea, egui_extras::TableBuilder, Modal, Area, ComboBox, Checkbox, Slider, ProgressBar, TextEdit, selectable_label.
Painter shapes for the waveform, ruler, playhead, status glyphs and transport icons. One linear gradient (a vertex-coloured Mesh) in the app icon tile only.
Shadow only on Modal and popups, through visuals.window_shadow and popup_shadow. No blur, no backdrop filter, no CSS-only layout.
Motion stays inside egui's animate_bool at the 90 ms and 160 ms tokens. The only continuous animation is a spinner while work runs.

How to read this canvas

Each window is drawn at 1280 by 820 pt, the app's default size. The light board carries an egui mapping strip under the window; the dark board beside it is the same screen in the dark theme.
Copy in the mockups is the app's own copy, taken from crates/ui and crates/app, so it reads the way the build reads.
PROPOSEDmarks anything the app doesn't do today.
Chords are shown as Ctrl, the way the in-window menu bar renders them on Windows and Linux. macOS shows Cmd.
